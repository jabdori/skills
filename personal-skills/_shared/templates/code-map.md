# 코드와 설명 지도

새 문서는 `docs/explain/code-map.md`에 두고 제출 전에 실제 코드·검사와 대조해 채웁니다. 사용자가 AI 없이 몇 분 안에 읽고 설명할 수 있게 씁니다.

## 코드 전체 지도

| 책임 폴더 | 맡은 일(한 줄) | 핵심 파일:줄·함수 | 이 폴더의 제출 파일 | 연결되는 파일·입출력 |
|---|---|---|---|---|
| [진입점/모델/자료/계산/검사/저장/화면·API/설정 중 실제 있는 것] |  |  |  |  |
