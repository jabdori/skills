# 인수 점검표

README의 번호별 요구사항을 `docs/인수점검표.md`에 빠짐없이 옮깁니다. 요구와 확인 방법은 [쉬운 말 기준](../personal-workflow.md#쉬운-말-기준)의 완전한 문장으로 쓰고, 근거에는 README 원문 위치와 검사 이름을 적습니다. `HOW_TO_RUN.md` 같은 제출 문서에는 넣지 않고 필요하면 링크만 겁니다(README가 위치를 명시한 경우만 예외).

| 요구사항 | 확인 방법 | 상태 | 근거(파일:줄 또는 검사 이름) |
|---|---|---|---|
| [누가 무엇을 해야 하는지 씁니다.] | [무엇을 실행·읽어 확인할지 씁니다.] | 아직 확인하지 않음 | [README.md:줄] |

상태는 `검사해서 통과함`(요구대로 동작함을 봄), `일부만 확인함`(확인하지 못한 부분이 남음), `아직 확인하지 않음`(검사 전), `아직 안 만듦`(기능이 없음)으로 씁니다.
