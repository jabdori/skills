# 제출 직전 설명 카드

제출 전에 실제 코드와 검사 결과를 대조해 채웁니다. 사용자가 AI 없이 5분 안에 읽고 각 분기를 직접 설명할 수 있는 길이로 남깁니다.

## 코드 전체 지도

| 제출 코드 파일 | 역할(한 줄) | 핵심 함수 | 주요 값 | 연결되는 파일·입출력 |
|---|---|---|---|---|
|  |  |  |  |  |

| 주요 분기: 무엇을 하는가 | 구현 결정(선택·대안·이유·한계) | 코드 위치(파일:줄) | 무엇으로 확인했나(테스트 이름·실행) | 확인 안 한 것·모르는 것 |
|---|---|---|---|---|
|  |  |  |  |  |

알고리즘·자료구조 선택(해당할 때): 선택 / 대안 / 이유 / 한계.

구조와 책임 분리: 계산 핵심과 화면·저장·입출력을 어디에 두었나 / 이유 / 합쳤다면 생길 문제.

## 주요 값과 근거

| 값 | 위치(파일:줄) | 근거 출처 | 바꾸면·그대로 두면 생기는 영향 | 확인한 것 |
|---|---|---|---|---|
|  |  |  |  |  |

확인한 범위보다 크게 말하지 않습니다. 서술형에서 모르는 부분은 약점과 실패 시 영향, 확인·개선 방법을 설명합니다.
