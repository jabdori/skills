# 요구 근거표

업무 요구가 처음 확인되면 `docs/요구근거.md`에 만듭니다(제출 문서에는 섞지 않고 링크만, README가 위치를 명시한 경우만 예외). 요구 칸에는 [쉬운 말 기준](../personal-workflow.md#쉬운-말-기준)으로 누가 무엇을 해야 하는지 완전한 문장을 쓰고, 근거 칸에는 `담당자 답변 / 제공 자료 / 코드·실행 결과 / 내 결정 / 미확인 가정` 중 실제 출처와 원문 위치·날짜를 적습니다.

| 요구·예외 | 근거 출처 | 구현 위치 | 확인 테스트·실행 | 상태 | 담당자 간 충돌·조율 결정 |
|---|---|---|---|---|---|
| [누가 무엇을 언제까지 해야 하는지 씁니다.] | [README.md:줄 또는 담당자·답변 시각] |  |  | 아직 안 만듦 |  |

상태는 `해야 할 일로 확정`(요구가 확인됨), `아직 안 만듦`(구현 전), `만들고 검사함`(실행 결과로 확인함), `담당자에게 확인 필요`(의미가 미정)처럼 씁니다. 이 말만 쓰지 말고 해당 행의 근거·검사도 채웁니다.
