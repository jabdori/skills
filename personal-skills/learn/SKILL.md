# 내 작업 이해하기

실제 코드·테스트·결정 문서·담당자 대화·세션 기록을 대조해 15분 안에 읽고 답을 연습할 짧은 학습 자료를 만듭니다. [explain의 결정 설명](../explain/SKILL.md#설명과-인계)과 [설명 카드](../_shared/templates/설명카드.md)의 근거·코드 위치·검증 연결을 재사용하되, 제출물에 없던 동작을 설명으로 채우지 않습니다.

1. 한 장에 입력 → 처리 → 출력과 외부 연동을 그린 뒤, 변경 전후 동작과 영향받은 실제 건수를 코드·자료·실행 결과로 비교합니다. 기록에만 있는 수치는 기록 출처를 밝히고 직접 재현한 결과와 구분합니다.
2. 결과를 가르는 경계값을 실제 값으로 실행해 입력·출력·코드 위치(파일:줄)를 적습니다. 실패 경로는 오류 메시지, 종료 코드, 부분 출력, 기존 파일 상태까지 확인하며 셸 리디렉션 같은 실행 방법의 영향도 구분합니다. 안전하게 실행할 수 없는 경로는 미확인으로 남깁니다.
3. 담당자 요구 ↔ 구현 위치 ↔ 확인한 검사 ↔ 보장/미보장을 짧게 연결합니다. 예상 확인 문제 5~6개를 먼저 제시하고, 그 아래 답을 **약점 → 파급 → 확인·개선** 순으로 적습니다. AI에 맡긴 일과 본인이 직접 확인한 일, 변경 전후, 경계값, 요구 충돌, 실패 동작, 검사의 보장 범위 중 실제 근거가 있는 유형을 고릅니다. 사용자 본인의 검증은 세션 기록으로 확인되지 않으면 대신 주장하지 않습니다.

시험·과제 작업 폴더에서는 별도 파일을 늘리지 않고 `설명카드.md` 또는 과제가 지정한 제출 문서에 `학습` 구역으로 합칩니다. 평소 프로젝트에서는 `docs/` 등 기존 문서 위치를 씁니다. 직접 실행한 사실·기존 기록·추정을 표시하고, 확인한 범위보다 크게 말하지 않습니다.
